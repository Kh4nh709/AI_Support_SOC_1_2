## Design notes for the coder prompts
- ② prompt: system template `investigate_system.txt` containing the word "JSON", the untrusted-data rule for every block, and "you have no tools; if data is missing answer need_more_data".
- The 7-day entity history is a single SQL per entity type using the correlation indexes; cap 50 entities.
- Digest job must be idempotent per day (re-running does not duplicate notifications).
- `notify.send(level, text)` never raises into the caller; failures are logged and counted.
- Health job writes one `system_health` row per run and sends only on state change (ok → alarm, alarm → ok) plus a daily 08:05 summary.
- The `investigate`, `digest` and `health` handlers register in `web/worker.py`'s job-type → handler table (DEC-037; P2-tasks.md hand-off 1) — `infra/worker.py` names no handler and imports no tier.
