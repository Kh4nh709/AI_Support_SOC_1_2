## Phase spec
**Objective.** Retire the two biggest unknowns before product code: does the model behave, and does the v3 schema apply cleanly.
**Deliverables.**
- `eval/smoke_test.py`: for 30 real alerts (from P0 fixtures / indexer probe) + 5 alerts with ≥ 30 KB raw_log (synthesise by padding a real log with realistic lines, clearly marked) + 3 adversarial alerts (instruction text in `data.dstuser`, in `full_log`, in `rule.description`), build a minimal ① prompt **that already obeys the block rules** (hand-written, no typed builder yet), call DeepSeek via the OpenAI SDK with `response_format={"type":"json_object"}`, validate against `triage_v2` (context pack §6.2), one repair round on failure. Record per call: JSON parse ok, schema ok, latency, `usage` tokens, estimated cost, first 300 chars of the response, whether `reasoning_content` was present. Write `docs/smoke-test-D1.md` with a summary table, p50/p95, pass/fail against thresholds (JSON valid ≥ 90 %, ≥ 98 % after repair, p95 ≤ 60 s, 30 KB prompt accepted), and — **amended 05/09 (DEC-022)** — 300-character excerpts only. The **full** raw responses go to `eval/results/smoke/` (git-ignored, verified), and the report names the path and the file count. The remote is a public GitHub repository and the responses quote real hostnames, usernames and internal IPs from live alerts; reproducibility is preserved by the files, which publication is not required for.
- Migrations flat in `docs/Schema/` (DEC-005; not `backend/migrations/`, not a `migrations/` subdirectory): `013_assets_enrichment.sql`, `014_intake_cursor_heartbeat.sql`, `015_labels_reviews_notes_eval_health.sql`, `016_alter_alerts_jobs_llm_runs_users.sql`, `017_append_only_and_roles.sql`, exactly implementing context pack §6.1; `make migrate` applies them in order on top of `schema.sql`; `conftest.py` uses the same path.
- `backend/tests/test_schema_v3.py`: tables and columns exist; CHECK sets match §5/§6; `intake` UNIQUE holds; `UPDATE audit_events` and `DELETE FROM llm_runs` as `app_rw` raise; `jobs.job_type` accepts `pull` and rejects `enrich`.
- Decision recorded: model accepted or fallback chosen (Owner + Director).
**Human-only.** Reading the smoke report; approving the model; providing the API key (already in `.env`).
**Exit gate.** `docs/smoke-test-D1.md` with numbers; migrations apply on a clean DB; `make test-db` green.
**Day budget.** 1 day. **Cut candidates.** None.
