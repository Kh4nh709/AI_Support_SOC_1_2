## Design notes for the coder prompts
- The labeling page reuses the P4 visibility filter but in "labeling mode" which strips **everything** LLM-related regardless of `suggestion_visible`; a dedicated test enumerates forbidden substrings: `suggested_action`, `gate_result`, `llm_`, `verifier`, `needs_review`, `false_positive` (as a verdict), `triage_status`, and `source` as a field with `replay`, `wazuh` and `lab` as its values (DEC-019).
- Labels are per labeler; the page must not reveal the other labeler's label.
- κ: use `sklearn.metrics.cohen_kappa_score` only if sklearn is already a dependency; otherwise implement the 3×3 formula directly (it is ten lines).
- Seed all randomness (`EVAL_SEED = 20260904`).
