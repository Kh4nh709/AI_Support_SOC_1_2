## Phase spec
**Objective.** Close the pilot, prove recoverability, hand the Owner everything the thesis report needs, tag the release.
**Deliverables.**
- `eval/pilot_export.py`: from `audit_events` (`tier1.decided`, `tier1.escalated`, `tier2.concluded`), `llm_runs`, `alerts.suggestion_visible`, `autoclose_reviews`: decisions per branch (blind / visible) and per analyst; median and IQR of acknowledge → decide per branch; Mann–Whitney only if n ≥ 30 per branch, otherwise counts only; agreement of ① with human decisions **on the blind branch only**; gate-forced `needs_review` rate; auto-close error rate from digest with Wilson 95 % CI; ② usefulness ratings (add a 1–5 rating field to the case conclude form if not present — INBOX if it needs a column; otherwise store in `case_notes` with a tag). Writes `docs/results/pilot.md`.
- Restore drill: `scripts/restore.sh` into an empty database, `make test-db`, row counts before/after; `docs/restore-drill.md` with timestamps and outcome (Owner signs).
- `docs/runbook.md` (≤ 2 pages): start/stop, env keys, backup/restore, alarms and what to do, common failures (indexer down, model down, cap reached, worker stuck), pilot rules.
- `docs/demo.md`: 10-minute demo script (pull → queue → ① reasons and gate → decide → escalate → ② → conclude → digest → eval tables) with seeded demo data instructions that do not touch the pilot data (`source='lab'`, tag `demo`).
- Bug-fix sweep: every open INBOX item is resolved, cut, or moved to `docs/limitations.md` with a sentence for the thesis.
- `docs/limitations.md`: the list from the architecture §9 plus anything discovered — **including (DEC-052) that the corpus contains asset-hygiene events, vulnerability-detector resolutions and CIS benchmark checks, which resolve to `unknown` because no playbook covers them: 12,217 alerts / 24 clusters / 0.8 % of 3,070, kept, labelled and reported rather than excluded, so every pilot number describes the estate and not a curated stream** — (author-as-labeler, 7-day pilot, single provider for proposer and verifier, no HA, no hash-chain, DeepSeek data egress, categories without lab alerts).
- Final: `eval/report.py` re-run, git tag `v1.0`, `docs/plan/STATE.md` closed.
**Tests required.** `pilot_export.py` on a fixture DB with known numbers; restore drill executed for real (not mocked); demo seed idempotent.
**Exit gate.** Restore drill report; `docs/results/pilot.md`; `docs/runbook.md`; `docs/limitations.md`; tag `v1.0`; demo rehearsed (Owner).
**Day budget.** 3 days, of which ≈ 1.5 days agent work; the rest is the Owner writing the thesis. **Cut candidates.** Demo polish; charts.
