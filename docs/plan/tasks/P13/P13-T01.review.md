- **M3 — the payload keys are a forward contract invented here.**
  - The plan fixes only `{entry_id}`, for `knowledge.approved` (plan:410) and `rag.integrity_failed` (plan:301). For reject and retire it names only a `reason: str` parameter (plan:412-413).
