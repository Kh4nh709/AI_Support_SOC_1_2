## 1. Built

### `rag/publish.py` (`python -m app.rag.publish --rebuild [--root PATH]`)

**Functions:**
- `approve(conn, draft_id, admin_id, *, edited=None, root=KB_LEARNED_ROOT) -> uuid.UUID`.
- `approve_published(...) -> Published(entry_id, path)` and `retire_published(...) -> Retired` are the real implementations.
- `commit_publication(conn, action)` commits; if the commit raises, it removes the file (approve) or moves it back (retire).
- `reject(conn, draft_id, admin_id, reason)`, `retire(conn, entry_id, admin_id, reason, *, root=)`, `rebuild(conn, root) -> int`.

**Errors:** `PublishError` is the base of `UnknownDraft`, `UnknownEntry`, `StaleDraft(reason: "not_pending"|"source_changed")`, `StaleEntry`, `InvalidReason` and `DraftInvalid(.faults)`.

**Approve:**
- **Lock:** the draft row is locked `FOR UPDATE`, and the UPDATE also says `AND status='pending'`.
- **Edits:** `edited` is laid over the 6 model fields only. A key outside them gives `DraftInvalid(["v1_schema:unexpected_key"])`; a non-mapping gives `["v1_schema:root"]`.
- **Closed fields:** the 6 closed fields always come from the *current* `source_record`.
- **Tidy and validate:** T04's `_tidy` / `_tidy_list`, plus `strip_invisible` on tags with de-duplication, then `validate_draft` against the current source.
- **Content:** exactly `render_entry_markdown({**fields, entry_id, version: 1})`.
- **The entry row:**
  - `fingerprint` = `alert_fingerprint` / `case_fingerprint(...).text`;
  - `file_path` = `entries/<category>/<entry_id>.md`;
  - `content_sha256` = `sha256_text(content)`;
  - `source_alert_ids` = `[alert]`, or the case's head ids; `source_case_ids` = `[case]`;
  - `evidence` = `[{subject, at}]`.
- **One savepoint:** the entry insert, the draft marked `approved` (its `draft` JSON becomes what was published), the event and the file write all happen in one savepoint, with the file last.
- **The file write:** a temp name in the same directory, `fsync`, `os.replace`, then an `fsync` of the directory. A path or symlink that leaves the root is refused (`PublishError`).
- **Category:** one that is not `[a-z0-9_]{1,64}` raises `PublishError`.

**Events:**

| Event | Payload | `subject_id` |
|---|---|---|
| `knowledge.approved` | `{"draft_id","entry_id"}` | the source id |
| `knowledge.rejected` | `{"draft_id","reason"}` | the source id |
| `knowledge.retired` | `{"entry_id","reason"}` | the entry id |

**Reason:** trimmed; 1–500 characters; no NUL and no lone surrogate.

**Retire:**
- `retired` status; `file_path` becomes `retired/<category>/<id>.md`, and the file is moved.
- A missing file is nothing to move. A path outside the root is never touched.

**Rebuild:**
- Active entries only.
- An entry whose content hash does not match, or whose path leaves the root, is skipped with a stderr JSON line.
- The CLI prints `{"rebuilt": N, "root": ...}`.

### Routes (all Admin; every POST needs a JSON content type, checked after the role)

**Error convention:**

| Status | Body |
|---|---|
| 404 | `{"detail":{"reason":"not_found"}}` |
| 409 | `{"detail":{"reason":"not_pending"\|"source_changed"\|"unpublishable"\|"not_active"}}` |
| 422, reason | `{"detail":{"field":"reason","reason":"required"\|"invalid"}}` |
| 422, malformed body | `{"detail":{"field":"body"\|"edited","reason":"invalid"}}` |
| 422, faults | `{"faults":["v3_ipv4:summary", ...]}` (flat; `rule:field` from `FAULT_VOCABULARY`) |
| 503 | `{"detail":{"reason":"publish_failed"}}` (nothing stored) |

**`GET /api/admin/knowledge/drafts?status=pending|approved|merged|rejected&limit=1..500(200)&offset=0`**
- Returns a list of `{draft_id, source_kind, source_id, conclusion, status, title|null, has_text, warnings, conflict_with_entry|null, duplicate_of_entry|null, created_at, reviewed_by|null, reviewed_by_name|null, reviewed_at|null, review_note|null}`.
- `pending` lists conflicts first, then oldest first. The other statuses list newest review first. An empty store gives `[]`.

**`GET /api/admin/knowledge/drafts/{draft_id}`** returns `{draft, source}`:
- **`draft`:** `{draft_id, source_kind, source_id, conclusion, status, draft:{12 fields}|{}, warnings, llm_run_id, duplicate_of_entry, conflict_with_entry, created_at, reviewed_by, reviewed_by_name, reviewed_at, review_note}`.
- **`source`:** `{kind, id, alert, case, investigation, decision, notes, enrichment, conflict_entry}`.
  - **Alert:** `alert` = exactly `GET /api/tier1/alerts/{id}` (`get_alert_view(mode="analyst")`).
  - **Case:** `case` = exactly `GET /api/tier2/cases/{id}`, and `investigation` = exactly `GET /api/tier2/cases/{id}/investigation`. The tests compare these byte for byte.
  - **`decision`:** `{event_type, actor_id, actor_name, at, payload}`, from the newest `tier1.decided` or `tier2.concluded`, with the payload redacted.
  - **`notes`:** the case notes; `[]` for an alert.
  - **`enrichment`:** for an alert, its `raw_payload.enrichment` or `null`; for a case, a map `{head_alert_id: block}`. Redacted.
  - **`conflict_entry`:** the full entry JSON, or `null`.
- A source row that no longer exists gives a 200 with nulls.

**`POST .../drafts/{draft_id}/approve`** with body `{edited?: {title?, summary?, distinguishing_signals?, check_next_time?, confidence_note?, tags?}}`; an empty body is fine.
- Success: 200 `{"entry_id"}`.
- A closed field in `edited` gives 422 `{"faults":["v1_schema:unexpected_key"]}`.

**`POST .../drafts/{draft_id}/reject`** with body `{reason}` returns 200 `{draft_id, status:"rejected"}`.

**`GET .../entries?status=active|retired&limit&offset`**
- Returns a list of `{entry_id, version, status, title, conclusion, category, mitre_ids, tags, soar_scenario, rule_ids, log_source, file_path, content_sha256, evidence_count, approved_by, approved_by_name, approved_at}`, newest first, with no Markdown.

**`GET .../entries/{entry_id}`** returns the flat entry: the list fields except `evidence_count`, plus `fingerprint`, `content`, `source_alert_ids`, `source_case_ids`, `evidence`, `supersedes_entry` and `integrity:{content_ok, file_ok}`.

**`POST .../entries/{entry_id}/retire`** with body `{reason}` returns 200 `{entry_id, status:"retired"}`, or 409 `not_active`.

**`GET .../tags`** returns `{"tags":[sorted], "descriptions":{tag:text}}`.

**`GET /api/admin/overview`** gains a last section, `knowledge: {pending, conflicts}`. Like the other sections, it fails on its own.
