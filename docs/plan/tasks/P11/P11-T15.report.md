## 2. The click latch (the Director's note)

TanStack Query 5 tells React a mutation is pending a tick late, so `disabled={isPending}` does not stop two clicks in one tick.
`DigestRowView` holds `const latch = useRef(false)`: `review()` returns when it is set, sets it, and calls
`mutation.mutate(verdict, { onSettled: () => { latch.current = false } })`. It is one latch per row, so a Đúng and a Sai fired in the same
tick on one row also send one POST. This is a local ref latch; **it is to be swapped for `useSubmitLatch` when P11-T14 lands it.**
Tests: "posts once for two clicks in the same tick" and "posts once for a Đúng and a Sai fired in the same tick on one row" (two
`fireEvent.click` with no await between them, one POST asserted). Red step (a) below shows them fail without the latch.

## 3. Deviations

1. **The attribution trailer is `Claude Sonnet 5.5`, not the brief's `Claude Opus 5.5`.** This Coder is Sonnet 5.5; the harness's attribution
   rule says so, and the merged P11-T13 commits carry it. The `Claude-Session` line is as the brief says.
2. **Refusals are said in the row, not in a page-level card or a toast.** The canvas draws the 409 and 422 texts as cards and the write
   failure as a bottom-right toast; spec §3 puts a text "in the dialog, at the field, or as a toast", and this page has neither dialog nor field.
   A text beside the row it is about is what a keyboard or screen-reader user needs (it is `role="alert"`, and the focus goes to it when the
   buttons it replaces are gone). The shared `Toast` is a success note and has no error kind.
3. **The 409 `not_auto_closed` sentence names the cluster** (`…1661001`, the canvas's wording) in a page string, `D.notAutoClosed(id)`;
   `S.admin.reason.not_auto_closed` (the same sentence without the id) is untouched and stays the generic text.
4. **404.** The brief says "`404 not_found` for a bad alert id". The handler answers `404 {reason: "not_in_digest"}` for an alert not on that
   day's digest, and `deps.clean_path_id` answers a plain `404 "not found"` for an id with a control character, which `parseAdminDetail` reads as
   `not_found`. Both are mapped. **`409 not_in_digest`: the handler does not send one** (it is a 404; a stale-page case is `409 not_auto_closed`).
5. **Own table markup, not `DataTable`.** The row needs its own class (amber, dimmed), its `data-alert-id` / `data-state` / `data-disagreement`
   and a per-row state; `DataTable` has no row hook, and adding one would touch a shared component other pages are changing. Same classes,
   caption and `scope="col"` headers as `DataTable`.
6. **Words from the canvas, with these changes:**
   - the day in a sentence is `dd/mm/yyyy`, not the canvas's `dd/mm` (the picker lets the admin choose any year);
   - ①'s suggestion is `S.ai1.action` (Dương tính giả / Cần xem xét / Chuyển tier 2), and the severity is `S.severity` in the band colour of its
     code (`low` is the blue of the canvas), where the canvas shows the raw codes (a code with no label is shown raw);
   - the subtitle drops the canvas's "· dữ liệu minh hoạ";
   - the span is the clock (`08:02 – 17:40`) only when both ends are on one day of the display zone, else `29/09 23:50 – 30/09 00:10`.
7. **Extra, not in the card:**
   - a focus hand-off (see "focus" above);
   - the 200's `reopened` marks the row even when the row's own flag is false;
   - `aria-busy` on a row while its POST is out.
8. **`AdminLayout.test.tsx`** lists `"DigestPage"` in `BUILT` as the Director ruled (`PAGES` and the titles test are whole).
   **`routes.test.tsx` is untouched:** its "lets admin open /admin/digest" renders the real page, whose GET is unhandled and fails after the test
   body, exactly as `LlmPage`'s does; nothing is printed and nothing fails, so no `vi.mock` was added.

Known behaviours, not fixed:
- The bad-day notice rides in the router's location state, which is `history.state`; a browser keeps that over a reload, so the notice may show
  again after a reload of the corrected URL. Not tested in a real browser.
- A window-focus read drops a row whose sentence is "không còn ở trạng thái tự đóng" (the server no longer lists it); the sentence goes with it.
- The summary counts the rows the list holds; a day's rows that the server filters out (Tier-1-reopened without a digest review) are not counted (the handler's docstring: such a row "leaves the list as before").
