### New findings

**n1 — Minor — `frontend/src/api/adminTypes.test.ts:113-118` (`dictKeys`)**
- **Evidence:** `const end = source.indexOf('"', i + 1); … i = end;` has no check for -1. An unbalanced `"` inside a pinned dict (a single-quoted value holding a `"`, or an escaped `\"`) sets `i = -1`, and the loop restarts at offset 0, forever. It is synchronous, so vitest's test timeout cannot stop it, and `make ui-test` hangs instead of failing.
  - A scratch copy of the helper on a copy of `admin_llm.py` with `"note": "a \" b"` in `limits_out` hung until it was killed.
  - A minimal case with a restart counter confirmed the loop (`indexOf returned -1: the scan restarts at 0`).
- **Fix:**
  - throw `unterminated string after: <anchor>` when `end === -1`;
  - optionally skip a backslash-escaped quote, and add `\s*` to the nine lookaheads so a ruff wrap does not trip them.
