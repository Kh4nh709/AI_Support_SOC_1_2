### Findings

**Minor 1: a fixture the handler cannot send; a real answer with no fixture.** `frontend/src/features/admin/DigestPage.test.tsx:1260` ("says a 503 timeout in the reason's own text") serves the GET `503 {reason:"timeout"}`. `api_digest` has no timeout handling; its only 503 is `deps.current_user`'s plain string `"auth disabled: JWT_SECRET unset"` (`backend/app/web/deps.py:131`), which has no GET fixture. The report's state table also lists "503 `timeout`" for this page. Behaviour is right: I swapped the fixture to the real string temporarily and asserted `D.loadErrorServer(503)` with no "auth disabled": green. **Fix:** serve `refuse(503, "auth disabled: JWT_SECRET unset")`, assert `D.loadErrorServer(503)` and `queryByText(/auth disabled/)` null, and correct the report row.

**Minor 2: no success toast, and the deviation is not recorded.** Spec §3 says "Every mutation invalidates the queries it touches and shows a toast", and the merged admin pages do (`LlmPage.tsx`, `FailedJobsBlock.tsx`). `DigestPage.tsx:150-154` shows the result in the row and moves the focus, but no `Toast`, and the report does not list this as a deviation. The canvas draws no toast, and a toast with a close button on every click of a list is noisy, so the choice is defensible. **Fix:** record it under Deviations (preferred), or show `<Toast>` "Đã ghi nhận: <verdict>" (the Jinja flash's words).

**Minor 3: the picker pushes a history entry per change.** `frontend/src/features/admin/DigestPage.tsx:416` calls `setParams` without `{ replace: true }` on every `onChange` of `<input type="date">`. When a year is typed, Chrome fires `input` for each intermediate valid date (`0002-…`, `0020-…`, `0202-…`), which the server accepts, so one typed year can give several GETs and history entries for Back to walk through. Not checked in a real browser. **Fix:** `setParams(next, { replace: true })`, or ignore years before 2000.

**Nit:** arbitrary hex classes (`text-[#aeb9c6]` …, 42 uses). They match the merged admin pages (LlmPage 27, OverviewBlocks 17), so no change asked.
