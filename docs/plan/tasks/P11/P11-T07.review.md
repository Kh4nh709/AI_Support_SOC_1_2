### Deviations judged

1. **The default day is today; the Jinja page defaults to yesterday.** Accepted. Spec §5.6 says "the default day is today in `DISPLAY_TZ`", and §4.5's "Hôm nay (đến giờ)" matches it. `today` is returned, so the UI can offer both.
2. **409 `not_auto_closed` for an alert that is no longer auto-closed** (accepted by the Director). The stale-page case is right: a same-day alert reopened by Tier 1 or by "Sai" answers 409, and the race window is still `StaleState`. Nothing leaks to a non-admin: the role check answers first, and the 409 body carries no data. But the implementation answers 409 for every existing alert that is not `auto_closed`. Synthetic ones and alerts never auto-closed included, so the ruling's "unknown, synthetic or other-day alerts are still 404" does not hold. See F1.
3. **Three reads in `tier1/digest.py`, not one.** Accepted. `test_router_has_no_raw_sql` forbids SQL in the router. For the small `rules_enabled` difference from the page, see Verified.
4. **`test_path_id_guard.py` edited.** Accepted. The route list must name the new route, and both endpoints are checked for `AlertId`.
5. **A day stricter than the page's.** Accepted. The plan's interface is `?day=YYYY-MM-DD`, and the React page keeps that form in its URL. `fullmatch` is redundant with Python 3.12's `date.fromisoformat`, which already refuses a trailing newline, space, `T…` or NUL (m5 is equivalent), but it is harmless.
6. **FastAPI's own 422 for a body that is not a JSON object, malformed JSON, or no JSON content type.** Accepted. Only a client that does not send a JSON object reaches it; the React page always sends one. The echoed `input` is the caller's own body, not server data. P11-T15's client must tolerate a list `detail` on a 422.
7. **A second review after "Sai" is `not_auto_closed`, not `already_reviewed`.** Accepted. It follows `digest.review`'s order (the status before the key) and the Jinja page's message, and the stale page shows the "no longer auto-closed" sentence. P11-T15 must not expect `already_reviewed` there.
