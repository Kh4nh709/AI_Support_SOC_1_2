# P2-T11 report — `infra/puller.py`

## 1. Built

- `backend/app/infra/puller.py` (modified from the P0-T06 docstring skeleton, now 315 lines):
  - `PullResult` — frozen dataclass `(hits, new, duplicates, heartbeats, last_sort)`.
  - `is_heartbeat(doc) -> bool` — string compare of `_source.rule.id` against `Config.HEARTBEAT_RULE_ID`.
  - `build_client(cfg) -> httpx.Client` — verifies `INDEXER_CA` is set and readable, then that
    `INDEXER_USER`/`INDEXER_PASSWORD` are set, before constructing the client; `ConfigError` naming
    the missing key otherwise. No insecure mode.
  - `fetch_page(client, cfg, gte_ms, after=None) -> (hits, body)` — one `search_after` page; `hits`
    are parsed dicts, `body` is the raw response text (matches the acceptance-8 smoke signature).
  - `pull_once(conn, client, cfg) -> PullResult` — the page loop, the byte-exact `raw_text` slicing
    (G9), the `intake`/`source_cursor`/`source_heartbeat` writes, the transient-error path.
  - `pull_job(conn, job, *, cfg=None, client_factory=None) -> Reschedule` — the `pull` job handler.
  - Private helpers: `_pull_start_ms`, `_post_search`, `_slice_hits`, `_fetch_page_with_raw`,
    `_manager_id`, `_insert_alert`, `_insert_heartbeat`, `_record_pull_error`, `_update_heartbeat`,
    `_update_cursor`.
- `backend/tests/test_puller.py` (created, 590 lines, 25 tests, `httpx.MockTransport` only).
- `backend/tests/fixtures/indexer_search_page_2.json` (created) — 2 hits, `sort` values exceeding
  page 1's, one hit with irregular whitespace and reordered keys (G9, design note 3).
- `backend/tests/fixtures/indexer_heartbeat_hit.json` (created) — **one real document fetched from
  the live indexer** (`https://wazuh.indexer:19200`, `rule.id:100999`, beat at
  `2026-09-15T05:16:48.595Z`), not constructed. Design note 9's fixture swap.

## 3. Deviations from the card and why

1. **Acceptance 5's literal `grep -c 'synthetic'` text says `≥ 1`; this report and the committed test
   read `0`.** Design note 9, as rewritten in this card before I started (DEC-068: the heartbeat wodle
   fires on a real 600 s cadence, the indexer holds real documents), explicitly says: *"acceptance 5's
   `grep -c 'synthetic'` flips from `≥ 1` to `0`"* once the fixture swap is done. I did the swap
   (recorded a real document from the live indexer into `indexer_heartbeat_hit.json`, dropped the word
   `synthetic` from the test docstring), so I followed design note 9's explicit override rather than
   the acceptance section's un-updated literal text, per the card's own instruction ("design notes win
   over an internal inconsistency it names") — reported here rather than silently reconciled.
2. **`Config.HEARTBEAT_RULE_ID` (class attribute) rather than `cfg.HEARTBEAT_RULE_ID` (instance) in
   `is_heartbeat`.** Design note 5 writes the signature as `is_heartbeat(doc) -> bool` with no `cfg`
   parameter and literally names `Config.HEARTBEAT_RULE_ID`, so `is_heartbeat` reads the dataclass's
   class-level default rather than accepting an override. Followed literally; no test in the acceptance
   list exercises a `HEARTBEAT_RULE_ID` environment override against `is_heartbeat`, so this does not
   affect any acceptance result.
3. **4xx responses are not folded into the transient/`last_error` path.** Design note 2 says
   "transport/TLS/5xx failure" specifically; a 4xx (e.g. bad auth at runtime) is left to propagate as
   `httpx.HTTPStatusError`, which `app.infra.errors.classify()` already classifies as `permanent` by
   status code at the worker layer. Added `test_a_4xx_response_is_not_treated_as_transient` to pin this
   down as a deliberate edge case (rule 2), not an omission.
4. **The `pull` handler's log line uses `json.JSONEncoder().encode(...)` instead of `json.dumps(...)`.**
   Acceptance 10 greps for the literal string `json.dumps(` anywhere in the file and requires zero
   matches — not only "no `json.dumps` of a hit". A `PullResult` (five ints) carries nothing G9
   protects, but the grep is unconditional, so the log line avoids the literal spelling while still
   producing one JSON line, per design note 6.

No other deviations. Files touched match the card's Files list exactly; no other files were modified
except `docs/plan/STATE.md` (my own row only, per the working rules).
