# Coder — P2-T15 report

## 1. Built

- **`eval/dedup_verify.py`** — offline fold of the coded dedup predicates over the Owner's archive
  export, verdict against a measured cluster count.
  - `read_archive(path) -> ArchiveStats` — parses every JSONL line with the merged
    `app.ingest.wazuh_parser.parse_wazuh_alert`; total, never raises (invalid JSON / non-object /
    a parser rejection are all counted and skipped).
  - `fold_clusters(alerts, cfg) -> list[Cluster]` — design note 2's fold: sorts by
    `(alert_time, alert_id)`, applies exactly `DEDUP_IDLE_GAP_MINUTES`, `MAX_CLUSTER_AGE_HOURS`,
    `MAX_CLUSTER_SIZE` (all three read from `Config`, never a literal), records which ceiling
    closed each cluster.
  - `clusters_per_day(clusters, tz)` / `storm_day_report(alerts, clusters, tz, day)` — bucket by
    local day (`Config.DISPLAY_TZ`), attributing each cluster to the day it opened.
  - `compute_verdict(clusters, expect, tolerance_pct)` / `build_report(...)` /
    `format_text(report)` / `format_json(report)` — assemble and render the CLI output.
  - `main(argv) -> int` — CLI entry point. Exit 0 verdict PASS, 1 verdict FAIL, 2 archive missing
    or unreadable (prints `app.infra.puller.OWNER_PROCEDURE` on stderr, reused rather than
    retyped).
- **`backend/tests/test_dedup_verify.py`** — 22 offline tests, no archive needed. Builds file A
  (A1–A6, six literal rows), file B (A7, generated: 1,001 alerts), file C (A8, generated: 31
  alerts) from `archive_line_5503.json`'s `event.original`; asserts the A1–A8 table, the six
  failing-case overrides from acceptance 2 (both the two originally-specified ones and the three
  DEC-077 discriminating replacements), rejected-line counting, local-day/storm-day bucketing,
  verdict boundary arithmetic, and the CLI (`main()`) including the exit-2 path and that no raw
  alert content reaches stdout.

No files were modified — both are new, matching the card's **Files — create** list exactly
(**Files — modify: —**).
