## 4 · Deviations

1. **One assertion in `test_tier2_api.py` changed, although the brief says the file stays green
   unchanged.** `test_case_detail_returns_heads_and_notes` asserted
   `"raw_log" not in body["heads"][0]` (P5-T06's "the overview grid carries no raw log"). The
   card's own requirement is that the heads now carry `raw_log`, so the two cannot both hold. It
   is now `assert "raw_log" in body["heads"][0]` plus `assert "risk_score" not in ...`, with a
   comment. Nothing else in that file, in `test_pages_cases.py` or in `test_conclude.py`
   changed.
2. **`tier2` cannot import `tier1`, but the moved rule calls `tier1.queue.risk_band`.** G1
   (`test_import_rules.py`, `ALLOWED["tier2"]`) forbids it, and a lazy import is flagged too.
   `case_view.head_band(score)` takes the thresholds from `llm.builder.risk_band` (0-24, 25-49,
   50-74, 75-100, which `tier2.dossier` already imports and `tier1.queue`'s `_BANDS` matches)
   and maps its four enum members to the four Vietnamese labels the queue rows carry. The value
   is what the Jinja page always showed ("Rất cao" for 83; ruling R8: rows keep the label).
   `test_head_band_label_is_the_tier1_queue_label` pins it to `tier1.queue.risk_band` for every
   score from -5 to 105, so the two copies of the four labels cannot drift unseen. The
   alternative, moving `risk_band` and `_BANDS` into `domain/` and re-exporting from
   `tier1/queue.py`, would edit a file outside this card's list, so I left it for the Director.
3. **A local variable is renamed.** In `enrich_heads`, `supplement = supplement(...)` would
   shadow the module-level function and raise `UnboundLocalError`, so the local is `extras`.
   The rule is otherwise line for line the moved one.
4. **Test fixture detail.** The tests set a head's `first_seen_at` together with `last_seen_at`
   (`ck_alerts_last_seen_khong_lui` forbids `last_seen_at` before `first_seen_at`, which defaults
   to `now()`), so a fixed `_T0`-relative timeline is possible. This is only in the new test
   file.
