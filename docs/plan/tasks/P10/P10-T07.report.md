## 1. Built

**Toolchain (`frontend/`).** Vite 8.3, React 19.2, TypeScript 6.0 (one strict `tsconfig.json`), Tailwind CSS v4 with
`@tailwindcss/vite`, Vitest 5 with jsdom 29 + Testing Library + `jest-dom` + axe-core, MSW (installed for P10-T08 onward, not
used yet), Playwright 1.63, ESLint 10 flat config (`typescript-eslint`, `react-hooks`, and `no-eval`, `no-implied-eval`,
`no-new-func` on), Prettier 3 (`printWidth` 100). `npm test` is `TZ=UTC vitest`. `package-lock.json` is committed and `npm ci`
was run from it. Dependencies at runtime: React, React DOM, React Router 8, TanStack Query 5, `@fontsource/ibm-plex-sans` and
`-mono`. `vite.config.ts` proxies `/api` (with `ws: true`) to `127.0.0.1:8000` for development and sets
`build.assetsInlineLimit: 0`, so no font is inlined as a `data:` URI (the CSP has `font-src 'self'`).

**`src/format.ts`.** `DISPLAY_TZ = "Asia/Ho_Chi_Minh"`; `formatTime` ("30/09 09:31") and `formatDateTime`
("30/09/2026 09:31:02"), both through `Intl.DateTimeFormat("vi-VN", { timeZone, hourCycle: "h23" })` and `formatToParts`. `null`,
`undefined` and `""` give "—". An offset in the input is honoured; a timestamp with no zone is read as UTC (the backend stores
UTC), never in the browser's zone; an unreadable value is shown as it came and never throws.

**`src/strings.ts`.** `export const S = {…} as const` with the labels of spec §4: app, nav, live, common, login, band, the ten
alert statuses of `alerts_pages.STATUS_LABELS`, queue, ai1, alert, decision, case, `caseStatus`, `conclusion` (exactly the three
conclusions), `headStatus`, ai2 (states, evidence marks, suggested conclusion, `stopped_by`). Plus
`labelOf(labels, code)`: the label of a server code, the code itself when there is none, "—" for null/undefined/"". It answers
only from the table's own string entries (`Object.hasOwn` and a `typeof` check), so `constructor`, `__proto__` and `toString`
are shown as text, not looked up on the prototype.

**`src/styles.css`.** `@import "tailwindcss"` and an `@theme` block with every token of the brief (ground #0D1117, surface
#141A22, border #263241, text #E6EBF1, muted #8593A3, ai-surface #17142A, ai-border #3A3170, ai-accent #A78BFA, the four bands
with their badge backgrounds, IBM Plex Sans and Mono). `main.tsx` imports the Fontsource latin, latin-ext and vietnamese
subsets, so the fonts are bundled files and there is no Google Fonts anywhere. `index.html` has `lang="vi"`, no inline script,
no inline style, no absolute URL. `public/favicon.svg` is our own.

**`src/app.tsx`.** A placeholder: a banner with the app name and a `<main>` with the two columns (alert, AI ①) built from the
tokens. P10-T08 replaces it with the router, the session and the header.

## 4. Deviations

1. **jsdom is pinned to `^29.1.1`, not the current major 30**: jsdom 30 needs Node `^22.22.2` and the host has 22.22.1
   (`EBADENGINE`). Raise it when the host Node moves.
2. **One `tsconfig.json`** (with `include` of `src`, `e2e` and the config files) instead of project references. Enough for a
   single app with no separate node project; `tsc --noEmit` covers everything.
3. **Files beyond the brief's list**: `@eslint/js` (required by the flat config), `frontend/.prettierignore`,
   `frontend/.dockerignore`, the `ui-install` target, and the extra tests (`tokens`, `strings`, `deploy`, `app`) and the
   non-vacuity guard.
4. **`nginx.conf` is the brief's config verbatim, so nginx resolves `app` when it starts.** If `app` is not resolvable at that
   moment (for example `docker compose up ui` alone, or `app` restarting), the `ui` container exits with
   `host not found in upstream "app"` and `restart: unless-stopped` retries. `depends_on: [app]` covers the normal start order.
   A `resolver 127.0.0.11` plus a variable in `proxy_pass` would remove it; I did not change the brief's config. The syntax of
   `nginx.conf` was checked only by `deploy.test.ts` (patterns), not by `nginx -t`, because I did not run a container.
5. **`make up` now also builds and starts `ui`** (it is `docker compose up -d` with no service named, and `ui` has no profile).
   This follows from the brief's compose entry; recorded so the Owner is not surprised.
6. **The guard's `eval(` needle also matches identifiers that end in `eval(`** (a function named `retrieval(` would trip it).
   It is the brief's needle; a rename fixes it. `deploy.test.ts` builds its forbidden host names from parts so that the card's
   own `grep -c "fonts.googleapis"` counts 0 in every file, the test files included.
7. **`npm audit`**: 0 vulnerabilities today; the line is advisory (`|| true`) as specified, so a future advisory will not fail
   `make ui-lint`.
8. **Library majors**: React Router is 8.x and Vitest 5.x in the lockfile; nothing in this card depended on an API that differs
   from the brief's snippets. MSW is installed and unused in this card.
