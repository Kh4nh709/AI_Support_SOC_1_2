### 7.1 Important: `app` was resolved once, at start (Director ruling R9) — `a5883b9`

**Deviation from the brief, recorded as R9 asks.** The brief's `nginx.conf` has a literal `proxy_pass http://app:8000`. nginx
resolves a literal host once, when it starts, so after `app` and `worker` are recreated (a new address) every `/api/` call
got a 502 until the `ui` container was restarted. `frontend/nginx.conf` now has, at server level,
`resolver 127.0.0.11 valid=10s ipv6=off;` (Docker's embedded DNS) and `set $app_upstream http://app:8000;`, and both
`/api/ws` and `/api/` say `proxy_pass $app_upstream;`. With a variable and no URI, nginx passes the original request URI
unchanged, so `/api/...` reaches the app exactly as before, and the name is asked again every 10 s at request time. The
`/api/ws` block also gained `proxy_set_header Host $host;` (the `/api/` block had it). A side effect that helps: `ui` now
starts while `app` is down (round 0's old deviation 4 is closed).

- Covering tests (`deploy.test.ts`, 24 tests now): "asks Docker's resolver for the app again and again, never once at
  start" (the `resolver` line, the `set` line, no `proxy_pass https?://` anywhere, exactly two `proxy_pass $app_upstream;`);
  "proxies the WebSocket upgrade on /api/ws to the app" and "proxies /api/ to the app on the same origin" (each now asks for
  `$app_upstream` and `Host $host`).
- Command: `docker run --rm -v "$PWD/frontend/nginx.conf:/etc/nginx/conf.d/default.conf:ro" nginx:alpine nginx -t`
  (no `--add-host`; the only container this round, authorised by the Director) —
  `nginx: the configuration file /etc/nginx/nginx.conf syntax is ok` and `nginx: configuration file /etc/nginx/nginx.conf test
  is successful`. The round-0 file (kept in scratch) fails the same command with `[emerg] host not found in upstream "app"`,
  which is the failure mode, seen once, that the variable removes.
- Red steps:
  - resolver line removed: `× asks Docker's resolver for the app again and again, never once at start` (1 failed, 23
    passed), `expected … to match /^\s*resolver\s+127\.0\.0\.11\s+valid…/m`.
