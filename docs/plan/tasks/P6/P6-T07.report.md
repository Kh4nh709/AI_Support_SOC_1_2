## 1 · Built

**`eval/build_gold.py`**
- **CLI.** `--archive-file` is now `default=None`. `--g2` on its own runs **G2-only** (no archive, no G1 fold, no `g1_*` output); `--archive-file` given keeps today's behaviour exactly. `--g1`, `--check-db`, or no flag without `--archive-file` exits **2** naming the missing flag (guard runs before `config.load`). New flag `--lab-scenarios PATH` (default `docs/lab-scenarios.md`). Module docstring run-lines and exit-code paragraph and the parser epilog updated; the G1 lines are marked "void since DEC-111, kept runnable as the record".
- **`expected_rules(path)`** parses the `#### Expected rules` tables under each playbook-category `### ` heading. Empty table, duplicate id across categories, or no table at all → `ExpectedRulesUnreadable` (exit 3). The runbook is the single source of truth (DEC-114); no id list in code.
- **Scope rule (`_g2_select`).** New keyword `expected`. Each in-window head is scoped by **`alerts.rule_id`**, never `alerts.category` (the category is the product's output; scoping by it would drop the mis-categorised scenario alerts the eval exists to count). A benign-block window (`category_expected == "benign"`) is unscoped. Out-of-scope heads are counted in `excluded_per_window` as `in_window_unexpected`, no row emitted. Returns `(rows, heads_per_window, excluded_per_window)`. `g2_rows` keeps its shape plus the `expected` keyword.
- **Truth.** `TRUTH_BY_KIND = {"attack": "escalate", "benign": "benign"}` (DEC-111 + the E5 amendment DEC-115 — the twin `false_positive` is withdrawn). `ClusterRow` gains trailing `scenario_id`, `kind`, `truth_label` (default `""`, so G1 rows are unaffected). `CANDIDATE_COLUMNS` gains the same three trailing columns.
- **Overlap refusal.** `assert_windows_disjoint` sorts each agent's windows and raises `OverlappingWindows` (exit 3) before any query; called both in `main` (before the DB is opened) and in `_g2_select`.
- **Coverage.** `coverage_document` gains a **G2-only** branch (title `# Gold coverage — G2 only`, a run header naming the windows/scenarios files and the declared-rule count, no `## G1`, floors = G2 + "G1: not built"). The windows table (both modes) gains `in scope` and `in_window_unexpected` columns and a totals line. The G2 table prints the window-truth counts (`escalate` / `benign`), the `≥ 20 benign` line, and `DEC111_SENTENCE` immediately after the enrichment line (new `coverage_table` keyword `after_enrichment_lines`; G1 passes nothing, so its section is byte-identical). `write_outputs` skips the two `g1_*` files when `g1_rows`/`g1_members` is `None`. The G2-only stdout headline is `G2 only · windows … · heads … · in scope … · in_window_unexpected … · G2 sample …`.

**`eval/label_export.py`**
- `Candidate` gains `scenario_id`, `kind`, `truth_label` (read with `row.get(...) or ""`, so the committed G1 file with no such columns still reads).
- `build_gold_rows`: a candidate with a non-empty `truth_label` freezes at that label, `adjudicated=False`, **whether or not the humans agree or labelled it** — it is never a `PartialLabelled`/`MissingFinalLabel` blocker (DEC-111). A `truth_label` outside `LABELS` raises `ValueError`. Candidates with no `truth_label` keep rules (i)–(iii) exactly. `GOLD_COLUMNS` gains trailing `scenario_id`, `kind`; `write_gold_csv` writes them.
- `vs_truth(candidates, pairs, a, b)` (pure): each labeller's `(truth_label, labeller_label)` pairs over the truth candidates they labelled → Cohen's kappa plus `accuracy` (= `p_o`, the human baseline P7 compares ① against) and `by_category`. `cmd_kappa` writes it under the new `vs_truth` key. One labeller's gap does not shrink the other's `n`; no truth rows → both `n=0`, `kappa=null`.
