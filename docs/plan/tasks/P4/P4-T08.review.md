Non-blocking notes:

1. **(b) card: five malformed but authenticated bodies return an unhandled `500` and are lost
   without a trace.** The card specifies them nowhere. Probed on the composed app, each gave
   `500 'Internal Server Error'` with `intake` and `rejected_alerts` both unchanged:
   - a body with `id` and `rule.id` but **no `timestamp`** (`KeyError` at `intake.py`'s
     `alert_obj["timestamp"]`);
   - an **unparseable `timestamp`** (`ValueError` in `_replay_sort_key`);
   - valid JSON in **UTF-16** (`json.loads` accepts it; `body.decode("utf-8")` then raises);
   - a **non-dict `_source`** (`is_heartbeat` indexes into it);
   - a `\u0000` inside a string (PostgreSQL rejects NUL when `raw_payload` is derived).

   The Coder built design note 1(b)'s reject set exactly as written: `not_json`, `not_an_object`,
   `id`, `rule.id`. The note 1(d) it uses `alert["timestamp"]` in, but never lists it as a
   required field. `phase-1-tiep-nhan-chuan-hoa.md` §Xử lý lỗi wants every "broken JSON /
   missing required field" case to be a `400` **with a `rejected_alerts` row**, because the
   integrator does not retry. No §2 invariant covers it, the route is disabled on this host
   (`503`), and a real Wazuh alert always carries `timestamp`. For the Director: a small
   follow-up card that adds `timestamp`, `bad_timestamp` and `not_utf8` to the reject set and
   guards the `_source` shape.
2. **(b) card: its DSNs are pre-DEC-105/DEC-104.** Items 1 and 5 name `postgresql:///soc_p4t08_test`
   (a socket DSN, i.e. the frozen native fallback) and the shared `soc_test`. The card was
   dispatched 20/09 14:30, DEC-105 landed 20:52 and the Coder ran before it, so the Coder is not
   at fault. Re-run here on a private TCP database.
3. **(b)/(c): `test_webhook.py`'s scratch fixture needs the `PG*` environment.** It builds
   `postgresql:///<name>_webhook_test` and calls `createdb`/`dropdb` bare. That reaches the
   docker cluster only while `dsn_env.py`'s exports are set. With a TCP `TEST_DATABASE_URL`
   alone, `createdb` goes to the socket and the module errors out (a `CalledProcessError`, not
   a skip, so it cannot pass silently). The pattern is copied verbatim from the approved
   `test_auth.py:95`, and `reviewer.md`'s preamble exports the variables. It is worth one line
   in the runbook, or a later fixture that derives host/port from `TEST_DATABASE_URL`.
