- **Design notes:**

  **1 · `receive(conn, body: bytes, source_ip: str, cfg: Config) -> Receipt`.** In this order, and nothing earlier than the size check reads the body: (a) `len(body) > cfg.MAX_PAYLOAD_BYTES` → `PayloadTooLarge` (`413`), before any parse; (b) `json.loads(body)` failure, or the decoded value is not an object, or no `id` / no `rule.id` → `INSERT INTO rejected_alerts (raw_payload, reason, source_ip) VALUES (%s, %s, %s)` with `raw_payload = {"body": <the text, ≤ 4 KB>}` when it was not JSON (or not an object) and the parsed object otherwise, `reason ∈ {"not_json", "not_an_object", "id", "rule.id"}` → `Rejected(reason)` (`400` — the route names the missing field, never an exception message); (c) heartbeat → `Receipt(kind="heartbeat", intake_id=None)` after `INSERT INTO intake (manager_id, source_alert_id, raw_text, sort_key, via, outcome, processed_at) VALUES (…, 'webhook', 'heartbeat', now()) ON CONFLICT (manager_id, source_alert_id) DO NOTHING` and `puller._update_heartbeat(conn, saw_alert=False)` (a same-package private helper; calling it is preferred over a second upsert on `source_heartbeat` — say so in a comment) — **the heartbeat test**: `is_heartbeat` in `puller.py` reads `doc["_source"]["rule"]["id"]`; a webhook body may arrive **bare** (the alert object itself, as the manager's integration posts it) or as an indexer hit; normalise **for the check only** — `hit = doc if "_source" in doc else {"_source": doc}` — and never for storage (G9: `raw_text` is the bytes as posted); (d) otherwise `INSERT INTO intake (manager_id, source_alert_id, raw_text, sort_key, via) VALUES (%s, %s, %s, %s, 'webhook') ON CONFLICT (manager_id, source_alert_id) DO NOTHING RETURNING intake_id` with `raw_text = body.decode("utf-8")` **unchanged**, `manager_id` = `manager.name` of the alert object (the same derivation as `puller._manager_id`), `sort_key = puller._replay_sort_key(alert["timestamp"])` (DEC-019: a posted document has no `sort`); `None` → `Duplicate` (`409`); else `enqueue(conn, "pipeline", str(intake_id))` in the same transaction and `Receipt(kind="alert", intake_id=…)`. `is_synthetic` is never set from the outside: the webhook cannot produce a row the pipeline would mark synthetic (phase-1 B5 — there is no such field in the body contract). `infra/intake.py` imports only stdlib, `psycopg`, `app.infra.*`.
