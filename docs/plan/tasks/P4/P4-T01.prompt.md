- **Design notes:**

  **1 · `infra/auth.py` — pure, imports only stdlib, `psycopg`, `argon2`, `jwt` and `app.infra.*`.** Public surface:
  - `hash_password(password: str) -> str` / `verify_password(hash: str, password: str) -> bool` using `argon2.PasswordHasher(time_cost=3, memory_cost=65536, parallelism=4, hash_len=32, salt_len=16)` (migration 011's parameters); `verify_password` returns `False` on `argon2.exceptions.VerifyMismatchError` **and** on any other `argon2.exceptions.Argon2Error` (a malformed stored hash is "no", not a 500).
  - `@dataclass(frozen=True) Claims(user_id: str, username: str, role: str, iat: float, exp: float)`.
  - `class LoginFailed(Exception)` with `.reason ∈ {"unknown_user", "bad_password", "inactive"}`; `class AccountLocked(Exception)` with `.locked_until: datetime`; `class Unauthorized(Exception)` with `.reason ∈ {"missing", "malformed", "expired", "unknown_user", "inactive", "logged_out"}`; `class AuthDisabled(Exception)` (empty `JWT_SECRET`).
  - `login(conn, username: str, password: str, cfg: Config) -> Claims` — in this order: `cfg.JWT_SECRET == ""` → `AuthDisabled` (before any SQL); `SELECT user_id, username, role, is_active, password_hash, failed_logins, locked_until FROM users WHERE username = %s FOR UPDATE`; no row → run `verify_password(DUMMY_HASH, password)` anyway (`should`: a timing-safe shape — `DUMMY_HASH` is a module constant produced once by `hash_password("")` at import) then `LoginFailed("unknown_user")`; `locked_until IS NOT NULL AND locked_until > now()` (compare in SQL: select `locked_until > now() AS locked` alongside — the DB clock, §9) → `AccountLocked(locked_until)` **without** checking the password; `not is_active` → `LoginFailed("inactive")`; wrong password → `UPDATE users SET failed_logins = failed_logins + 1, locked_until = CASE WHEN failed_logins + 1 >= %s THEN now() + (%s || ' minutes')::interval ELSE locked_until END WHERE user_id = %s RETURNING failed_logins, locked_until` with `cfg.LOGIN_MAX_FAILS`, `cfg.LOCKOUT_MINUTES` → if now locked raise `AccountLocked`, else `LoginFailed("bad_password")` — **the caller commits before it raises** (note 4); correct password → `UPDATE users SET failed_logins = 0, locked_until = NULL WHERE user_id = %s` and return `Claims(iat=time.time(), exp=iat + cfg.JWT_TTL_HOURS * 3600)`. The fifth wrong password locks (`failed_logins` reaches 5 = `LOGIN_MAX_FAILS`); the sixth attempt, right or wrong, is `AccountLocked`.
  - `issue_token(claims: Claims, cfg: Config) -> str` — `jwt.encode({"sub": user_id, "role": role, "iat": iat, "exp": exp}, cfg.JWT_SECRET, algorithm="HS256")`; `iat`/`exp` are **floats** (planning decision 8: a logout and a new login in the same second must not collide).
  - `verify(conn, token: str, cfg: Config) -> Claims` — `AuthDisabled` on an empty secret; `jwt.decode(token, cfg.JWT_SECRET, algorithms=["HS256"], options={"require": ["sub", "role", "iat", "exp"]})` → `Unauthorized("malformed")` on `jwt.InvalidTokenError`, `Unauthorized("expired")` on `jwt.ExpiredSignatureError` (catch it first — it is a subclass); then **one SELECT by primary key**: `SELECT username, role, is_active, sessions_invalid_before, EXTRACT(EPOCH FROM sessions_invalid_before) FROM users WHERE user_id = %s` → no row → `Unauthorized("unknown_user")`; `not is_active` → `Unauthorized("inactive")`; `sessions_invalid_before IS NOT NULL AND iat <= epoch(sessions_invalid_before)` → `Unauthorized("logged_out")`; **the role in the returned `Claims` is the row's, never the token's** (a test changes the row's role after issuing and asserts the new one is returned).
  - `logout(conn, user_id: str) -> None` — `UPDATE users SET sessions_invalid_before = now() WHERE user_id = %s`.
  - `create_user(conn, *, username, display_name, role, password) -> str` — `INSERT INTO users (user_id, username, display_name, role, password_hash) VALUES (gen_random_uuid(), …) RETURNING user_id` (`gen_random_uuid()` is core in PostgreSQL 13+; `user_id uuid PRIMARY KEY` has no default — `schema.sql:677`), then the `admin.user_created` audit row. **`infra` may not import `audit`** (`ALLOWED["infra"]` is empty, and `test_import_rules.py` scans this module's source — including its `main()`), so `create_user` executes the audit INSERT **itself with plain SQL** — `INSERT INTO audit_events (event_type, subject_id, actor_id, actor_role, payload) VALUES ('admin.user_created', %s, NULL, 'system', %s)` (`Jsonb`), the same statement `audit.events.write_event` runs, with a comment saying why it is duplicated here (G1: `infra` cannot import `audit`; the CHECKs are the database's). `write_event` is not imported. The role is validated against `("tier1", "tier2", "admin")` in Python before the INSERT so the error names the role, not a CHECK.
  - `set_password(conn, username, password) -> bool`, `deactivate(conn, username) -> bool` (`UPDATE … SET is_active = false, sessions_invalid_before = now()` — a deactivated user's tokens die at the same moment).
  - **CLI** (`python3 -m app.infra.auth …`, `main(argv) -> int`, `argparse` subcommands): `seed-users --user USERNAME ROLE DISPLAY_NAME` (repeatable, `nargs=3`), `set-password USERNAME`, `deactivate USERNAME`; common `--env-file .env` / `--dsn DSN` (the DSN is never printed). Passwords come from `os.environ.get(f"SEED_PASSWORD_{USERNAME.upper().replace('-', '_')}")`, else `getpass.getpass(f"password for {username}: ")`; **`argv` never carries a password** (a test asserts the parser has no `--password`). `seed-users` is idempotent: an existing username prints `exists, skipped: <username>` and changes nothing (never overwrites a hash); each creation prints `created: <username> (<role>)`; one transaction per user, committed as it goes; exit 0 when every requested user exists afterwards, 1 on a bad role or an empty password, 2 on DSN failure.

  **2 · `web/deps.py` — the FastAPI glue (imports `infra.auth`, `infra.db`, `infra.config`, `audit.events`).** `get_conn()` — moved here **unchanged in behaviour** from `main.py` (commit on success, rollback on `BaseException`, close always); `main.py` imports it (`from app.web.deps import get_conn`) so `main.get_conn is deps.get_conn` and the existing override keeps working. `get_config() -> Config` (`config.load()`, overridable in tests). `Conn = Annotated[psycopg.Connection, Depends(get_conn)]`, `Cfg = Annotated[Config, Depends(get_config)]`. `COOKIE_NAME = "soc_session"`. `read_token(request) -> str | None`: `Authorization: Bearer <t>` first, else the cookie. `current_user(request, conn: Conn, cfg: Cfg) -> Claims`: no token → `401 {"detail": "not authenticated"}`; `AuthDisabled` → `503 {"detail": "auth disabled: JWT_SECRET unset"}`; `Unauthorized(reason)` → `401 {"detail": reason}`. `require_role(*roles: str)` → a dependency factory returning `Claims`; on a role outside `roles`: `write_event(conn, "authz.denied", request.url.path, "admin" if claims.role == "admin" else "analyst", actor_id=claims.user_id, payload={"required": list(roles), "role": claims.role, "method": request.method})`, **`conn.commit()`**, then `HTTPException(403, {"detail": "forbidden"})` (note 4). `ROLE_TO_ACTOR = {"tier1": "analyst", "tier2": "analyst", "admin": "admin"}` is the mapping the two audit CHECKs need.
