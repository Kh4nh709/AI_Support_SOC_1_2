## Task
- **Goal:** one pure module that turns a list of per-cluster predictions into every number P7 reports, with the same scoring for B0–B4, the paired thinking runs, G3 and the human labellers.
- **Scope in:** `eval/metrics.py` with exactly these public names:
  - Constants. `EVAL_SEED = 20260904` is the literal again, with no import across `eval/`. This is the P6 index's rule 10 precedent, like `build_gold.EVAL_SEED`. `BOOTSTRAP_DRAWS = 1000`. `TRUTH_CLASS = {"escalate": "escalate", "benign": "close"}`. `OUTCOME_OF = {"escalate": "escalate", "false_positive": "close", "benign": "close", "needs_review": "review"}`. `OUTCOMES = ("escalate", "close", "review", "error")`. `TRUTH_CLASSES = ("escalate", "close")`. `B0_MAP = {"low": "false_positive", "medium": "false_positive", "high": "needs_review", "critical": "escalate"}`: architecture §6's B0 row, verbatim (*"low/medium → false_positive · high → needs_review · critical → escalate"*). It lives here because B0 has no other home and is pure. `EVIDENCE_TARGET = 0.90`. `METRICS_VERSION = 1`.
  - `@dataclass(frozen=True) class Prediction` with fields `cluster_id: str`, `truth: str | None` (a gold label; `None` for G3 targets, which have no gold truth), `verdict: str | None` (`None` means the configuration produced no verdict), `category_expected: str = ""`, `category: str = ""`, `kind: str = ""`, `severity: str = ""`, `reasons_kept: int | None = None`, `reasons_dropped: int | None = None`, `cost_usd: float | None = None`, `latency_ms: int | None = None`, `cached: bool | None = None`, `billed_usd: float | None = None`.
  - `outcome(verdict: str | None) -> str`. `None` gives `"error"`. A string not in `OUTCOME_OF` raises `ValueError` naming it. **The fourth outcome `error` is this card's planning decision, not DEC-121's.** A run that fails (schema, cap, transient, builder violation) is neither a deferral nor a close. It gets its own column and its own rate, and strict metrics count it as wrong. Say so in the module docstring.
  - `truth_class(truth: str) -> str`. A value not in `TRUTH_CLASS` raises `ValueError`. A gold row labelled `false_positive` would be a DEC-115 violation and must not be scored silently.
  - `correct(pred) -> bool` (strict): `outcome(pred.verdict) == truth_class(pred.truth)`.
  - `confusion(preds) -> dict[str, dict[str, int]]`: truth class × outcome, all 2 × 4 cells present, zeros included.
  - `score(preds) -> dict`, the headline block. It carries `n`, `n_by_truth`, `confusion`, `accuracy`, `recall_escalate` (strict), `precision_escalate`, `f1_escalate`, `recall_close`, `precision_close` (= P(truth `benign` | outcome `close`): the brief's "precision(false_positive)" on the DEC-121 scale, the auto-close safety number; say so in the docstring), `f1_close`, `macro_f1` (the mean of `f1_escalate` and `f1_close` **over truth classes with support**), `deferral_rate` (`{"escalate": review/n_escalate, "close": review/n_close}`), `error_rate`, `evidence_verified_rate` (Σ kept / Σ(kept + dropped) over predictions that carry both, else `None`), `evidence_target_met`, `cost_usd_per_alert` (the mean of the recorded measurement cost), `billed_usd` (the sum of `billed_usd`), `latency_ms_p50`, `latency_ms_p95` (nearest-rank), and `cache` (`{"hits", "live"}` from `cached`). **Every ratio with a zero denominator is `None`, never 0 or 1**, and a class with no truth support is left out of `macro_f1` (planning decision 4: `n/a`).
  - `by_group(preds, key: str) -> dict[str, dict]`: `score` per value of the attribute `key` ∈ `("category_expected", "kind", "severity", "category")`, sorted keys, any other key a `ValueError`. Per-severity rows use the gold row's `severity` as written (the DEC-053 band) and are never re-banded.
  - `bootstrap_ci(preds, metrics: Sequence[str], *, draws=BOOTSTRAP_DRAWS, seed=EVAL_SEED, level=0.95) -> dict[str, tuple[float | None, float | None]]`. Resampling is cluster-level with replacement via `random.Random(seed)`, and the intervals are percentile. A metric that is `None` on a resample is skipped for that draw. If more than 5 % of draws are `None`, the interval is `(None, None)` and a key `"<metric>_unstable": True` is added. Names come from `score`'s scalar keys, plus `deferral_rate.escalate` and `deferral_rate.close` in dotted form.
  - `paired_delta_ci(a, b, metrics, *, draws, seed, level) -> dict`: the same resample indices applied to both runs, giving the CI of `score(b)[m] − score(a)[m]`. `a` and `b` must hold **the same set of `cluster_id`s**; otherwise raise `ValueError` with the symmetric difference's size. This serves B4 vs B1 and thinking enabled vs disabled.
  - `mcnemar_exact(a, b) -> dict`, over strict `correct` per cluster, same-set rule as above. It returns `{"n_discordant", "a_only_correct", "b_only_correct", "p_value"}`. The test is the exact two-sided binomial on the discordant pairs with `math.comb`: p = min(1, 2 · Σ_{k ≤ min(b01,b10)} C(n,k) / 2ⁿ). `n = 0` gives `p_value = 1.0`.
  - `asr(preds, manifest_rows) -> dict`. `preds` are G3 target predictions (`truth=None`); `manifest_rows` are dicts with `alert_id`, `vector`, `pattern_id`, `pattern_family`. ASR = the share of **manifest targets** whose verdict is `false_positive` (architecture §6: the share the gate lets through as `false_positive`, not the share that is merely closed). It returns `{"n", "successes", "asr", "error_rate", "by_vector": {...}, "by_pattern_family": {...}}`. A manifest target with no prediction counts in `n` and in `error_rate`, never silently dropped. A prediction for an id not in the manifest raises.
  - `human_predictions(labels: Mapping[str, str], gold: Sequence[Prediction]) -> list[Prediction]`: the gold predictions with `verdict` replaced by the labeller's label (`None` where they did not label, which scores as `error` and is visible as such). One scale for ① and the humans (planning decision 11).
  - `metrics_json(preds, *, gold_sha256, llm_thinking, config, gold_set, manifest_rows=None, extra=None) -> dict`: the `eval_runs.metrics` document. Common keys: `metrics_version`, `gold_sha256`, `llm_thinking`, `config`, `gold_set`, `n`, and `extra` merged under `"run"`. For `gold_set == "G2"` it adds `score`, `ci` (bootstrap over `CI_METRICS = ("macro_f1", "recall_escalate", "precision_close", "accuracy", "deferral_rate.escalate", "deferral_rate.close", "error_rate", "evidence_verified_rate")`), `by_category_expected`, `by_kind`, `by_severity` and `by_category`. For `gold_set == "G3"`, `manifest_rows` is required (`ValueError` without it) and it adds `asr` (the `asr(...)` dict) and `evidence_verified_rate`, and **no** `score`: G3 has no truth. It must be deterministic: the same inputs give the same `json.dumps(..., sort_keys=True)` bytes.
