## Task
- **Goal:** one read-only command turns a frozen gold sha's evaluation runs into three committed markdown files and one committed CSV. Rendering the same inputs twice gives byte-identical output. A reader cannot miss the corpus caveat, the deferral next to recall, the human baseline, or a dropped category.
- **Scope in:** `eval/report.py` (today a one-line stub). CLI: `--gold-sha HEX` (required), `--run-ids UUID,...` (optional explicit selection), `--results-dir eval/results`, `--kappa eval/kappa_v1.json`, `--human eval/results/human_<gold12>.json` (default derived from the sha), `--fewshot-decision eval/results/fewshot_decision.json` (optional, P7-T07's), `--gate-decision PATH` (optional, P7-T06's JSON), `--out-dir docs/results`, `--charts/--no-charts` (default: on if `matplotlib` imports), `--env-file`/`--dsn`. It writes:
  - **`ablation.md`**, top to bottom:
    1. The two caveat lines, verbatim: `DEC111_SENTENCE` and *"The class balance is the lab schedule's, not nature's; no rate here is an estate rate (DEC-111)."*
    2. The run table. Columns: config, thinking, prompt_version, model_id, n, the eval_run_id's first 8 characters.
    3. The headline table, one row per G2 run. Columns: macro-F1 [CI], recall(escalate) strict [CI], **deferral(escalate) [CI]** as the adjacent column, precision(close) [CI], deferral(close), error rate, evidence-verified rate (with ✓/✗ against 0.90, B2–B4 only), cost/alert, billed, p50/p95 latency.
    4. The truth × outcome table per run, 2 × 4.
    5. **The human baseline.** Labellers a and b scored with `metrics.human_predictions` on the same scale, plus `kappa_v1.json`'s strict `vs_truth` accuracy beside them. It is labelled "a second result, not the gold (DEC-111)". A missing human file prints `(not available — run_configs.py human)` and is never skipped silently.
    6. **B4 vs B1.** `paired_delta_ci` for macro-F1 and recall(escalate) strict, and `mcnemar_exact`.
    7. **The paired thinking ablation (DEC-042).** B4 disabled vs B4 enabled on the same clusters: each metric's delta [CI], McNemar, cost and p50/p95 for both, with the `llm_thinking` value of each run printed from its `metrics`, never inferred.
    8. **Prompt v1.1.** Either the gate decision (T06's JSON) or the line `prompt v1.1: not built — <reason from fewshot_decision.json> (DEC-116, DEC-121 Q2)`. If neither file exists: `prompt v1.1: no decision recorded`.
  - **`per_category.md`.** The caveat lines, then `by_category_expected` per run (rows per category; columns n, recall(escalate) strict, deferral(escalate), precision(close), macro-F1), then `by_kind` and `by_severity` (phase-1:148 band as written, never re-banded), then `by_category`, the product's own category, headed *"secondary view: the system under test's category"*. **Categories with no gold cluster** are listed under "Dropped (no gold cluster; never synthesised)", compared against the eight lab categories. `web_attack` and `policy_violation` are named with DEC-055/DEC-057.

Columns exactly: `gold_sha12, eval_run_id, gold_set, config, llm_thinking, prompt_version, cluster_id, alert_id, truth, verdict, outcome, correct_strict, category_expected, category, kind, severity, cached, cost_usd, latency_ms, error`. Rows are sorted by (`gold_set`, `config`, `llm_thinking`, `prompt_version`, `cluster_id`) and the output is UTF-8 with `\n` line endings. **No free-text column exists.** `error` is the exception class name only.
