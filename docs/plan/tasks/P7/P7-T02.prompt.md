## Task
- **Goal:** anything that calls `adapter.complete(...)` — `llm.triage.propose` and `verify` included — can be handed a `CachingAdapter` that answers a repeated measurement from disk, never serves one thinking mode's answer for the other, refuses to spend past the cap, and runs a list of work items at most four at a time.
- **Scope in:** `eval/llm_cache.py` with:
  - `fold_nonce(text) -> str` — finds the nonce carried in `nonce="<16 hex>"` attributes and replaces **every** occurrence of that value with `NONCE`. Zero nonces → text unchanged. **Two or more distinct nonce values in one message → raise `NonceAmbiguous`** (a builder defect; never cache it).
  - `CachingAdapter(inner, *, cache_dir: Path, thinking: str, spend: SpendGuard | None = None)` exposing the same keyword-only `complete(...)` signature as `DeepSeekAdapter` and returning the same `LLMResult` shape. Key = `smoke_test.cache_key(model, system, fold_nonce(user), thinking)` where `model` is the resolved request model. **`thinking` is a required constructor argument with no default**; a value outside `("enabled", "disabled")` raises. On a hit it returns the recorded result and does not call `inner`; on a miss it calls `inner`, writes the entry atomically (temp file + rename), and returns it. Each returned result is marked `cached: bool` (an attribute or a side record your harness can read — say which in the report).
  - `SpendGuard(month_spend_usd: Callable[[], float], cap_usd: float, cfg)` — tracks this run's **live** (non-cached) spend with `adapter.cost_usd`; `check()` raises `LLMBudgetExceeded` when `month_spend_usd() + live_spent >= cap_usd` **before** a live call; cached hits cost nothing and never trip it.
  - `estimate_cost(n_alerts, calls_per_alert, usd_per_call) -> float` and `refuse_if_over(estimate, month_spend, cap)` raising a clear `CostRefused` with the three numbers in the message.
  - `run_bounded(items, fn, *, max_workers=4) -> list` — results in input order; `max_workers > 4` raises `ValueError` (the brief's ceiling); an exception in one item is captured per item (returned as a failed result), never aborts the others.

- **Design notes:**

  **1 · One formula, not two.** Import `cache_key` from `eval/smoke_test.py` (load it the way the tests load eval scripts, or as a sibling module) rather than re-typing it. A test pins that `CachingAdapter`'s key for a given call equals `smoke_test.cache_key(...)` for the same inputs with the nonce folded.

  **2 · Why the nonce is folded.** §7.1 makes every build's nonce fresh, so an unfolded key would miss on every re-run and "re-runs are free" (the brief) would be false. Folding keeps the key stable across builds of the same alert, while the thinking mode, the model and the system prompt (the template) still separate measurements.

  **3 · A cache entry is a measurement.** Store `content`, `model`, `usage`, `latency_ms`, the key inputs' digests (never the full prompt text — context pack rule 11: never log full prompts), and the timestamp of the live call. Latency and usage reported for a cached hit are the recorded ones (the measurement's), and `cached=True` lets P7-T03 separate "cost of the measurement" from "billed in this run".

  **4 · Tests (`backend/tests/test_llm_cache.py`, pure).** `test_hit_avoids_the_inner_adapter` (a counting fake: two identical calls → 1 inner call); `test_thinking_mode_separates_entries` (same prompt, `enabled` vs `disabled` → two inner calls, two files); `test_nonce_is_folded_across_builds` (two user messages differing only by nonce → one inner call); `test_two_distinct_nonces_refuse`; `test_thinking_has_no_default` (constructing without it is a `TypeError`); `test_key_equals_smoke_test_formula`; `test_spend_guard_trips_before_a_live_call_and_ignores_hits`; `test_refuse_if_over_names_the_numbers`; `test_run_bounded_keeps_order_caps_workers_and_isolates_failures` (≤ 4 in flight, observed with a barrier or a counter); `test_atomic_write_leaves_no_partial_file` (simulate a failure mid-write).

  **5 · Red steps (DEC-025), each shown once and restored:** (a) drop `thinking` from the key → `test_thinking_mode_separates_entries` red; (b) stop folding the nonce → `test_nonce_is_folded_across_builds` red; (c) let a cached hit add to the live spend → the spend-guard test red.
