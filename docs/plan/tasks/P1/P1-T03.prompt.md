  **8 · G9 lives in `raw_text`; `raw_payload` is derived (DEC-023).** `jsonb` normalises: measured,
  `'{"b":1,"a":2,  "c":3}'::jsonb::text` is `{"a": 2, "b": 1, "c": 3}` — keys reordered, whitespace
  collapsed — so no byte-compare can pass against a `jsonb` column. `raw_text text NOT NULL` holds
  exactly what was read (server encoding is `UTF8`; JSON text is UTF-8 by RFC 8259, so `text`
  preserves every valid input byte and rejects invalid UTF-8 loudly). `raw_payload` is
  `GENERATED ALWAYS AS (raw_text::jsonb) STORED` — never inserted, always derived, and it doubles as
  the well-formedness check: inserting `'not json'` fails with `invalid input syntax for type json`.
  Nothing in P1 reads inside it; P2 may index it (`CREATE INDEX … USING gin (raw_payload)` builds).
  **The byte-compare test that actually tests the claim** — put this shape in
  `test_schema_v3_014.py`, parametrised over two fixtures that `jsonb` rewrites (any real indexer
  hit qualifies — `jsonb` orders keys by length, then bytes; `backend/tests/fixtures/` has five
  `indexer_sample_rule*.json`, and DEC-019's archive-line shape needs one more, which you write by
  taking one `_source` object out of such a file, verbatim):

  ```python
  @pytest.mark.db
  @pytest.mark.parametrize("fixture", ["indexer_sample_rule5503.json", "archive_line_5503.json"])
  def test_raw_text_round_trips_byte_identical(db, fixture):
      raw = (FIXTURES / fixture).read_bytes()
      with db.cursor() as cur:
          cur.execute(
              "INSERT INTO intake (manager_id, source_alert_id, raw_text, via) "
              "VALUES ('m', %s, %s, 'pull') RETURNING intake_id",
              (fixture, raw.decode("utf-8")),
          )
          (intake_id,) = cur.fetchone()
          cur.execute("SELECT raw_text, raw_payload::text FROM intake WHERE intake_id = %s", (intake_id,))
          raw_text, payload_text = cur.fetchone()
      assert raw_text.encode("utf-8") == raw     # the claim
      assert payload_text != raw_text            # the control: jsonb DID rewrite this fixture, so a
                                                 # jsonb column could not have passed the line above
  ```

  Without the control line a canonical-form fixture passes against plain `jsonb` too, which is
  exactly the test that would have let G9 stay unimplemented. Note for P2 (not your task):
  `json.loads` → `json.dumps` is **not** "the received bytes"; the puller slices the hit object out
  of the response body, the webhook stores the request body, replay stores the archive line.
