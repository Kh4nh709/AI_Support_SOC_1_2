Helpers: `_make_alert`, `_make_user`, `_make_case` (one insert helper per parent table, filling every `NOT NULL` column with no default); `rejects(db, sql, params)` (savepoint-wrapped rejection assertion, matching the pattern in `test_schema_v3_016.py`); `columns_present`, `_uuid`.
