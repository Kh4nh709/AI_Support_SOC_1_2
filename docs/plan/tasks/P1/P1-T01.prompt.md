  **8 · Cost, and why the report needs a reasoning column.** Verified today on a trivial prompt:
  `usage.completion_tokens = 41`, of which `usage.completion_tokens_details.reasoning_tokens = 35`

  billed at the output price, and output is priced at `LLM_PRICE_OUT_PER_M=0.66` against
  `LLM_PRICE_IN_PER_M=0.014` — a factor of **47**. Therefore:
  `cost_usd = prompt_tokens/1e6 * LLM_PRICE_IN_PER_M + completion_tokens/1e6 * LLM_PRICE_OUT_PER_M`,

  own **`reasoning_tokens`** column and the summary reports reasoning as a percentage of
  completion tokens. This is the only chance to size it before P3.

  returns them, `.env` has no cache price key, and P3 will want the counters.
