- **Design notes:**

  **1 · The surface.**
  ```python
  @dataclass(frozen=True)
  class LLMResult:
      content: str          # choices[0].message.content, or "" when absent — never reasoning_content
      model: str            # response.model, falling back to the requested model
      usage: dict           # {"prompt_tokens", "completion_tokens", "total_tokens", "reasoning_tokens",
                            #  "prompt_cache_hit_tokens", "prompt_cache_miss_tokens"} — eval/smoke_test.py:usage_dict, verbatim rules
      latency_ms: int

  class LLMTimeout(TransientError): ...          # the wall-clock deadline expired
  class LLMBudgetExceeded(PermanentError): ...   # monthly cap reached before the call
  class LLMPermanent(PermanentError): ...        # 4xx, or retries exhausted on a permanent error

  class DeepSeekAdapter:
      def __init__(self, cfg: Config, *, client: Any | None = None, spent_usd: Callable[[], float] = lambda: 0.0,
                   sleep: Callable[[float], None] = time.sleep, clock: Callable[[], float] = time.monotonic) -> None: ...
      def complete(self, *, system: str, user: str, response_format: dict | None = None,
                   timeout_s: float | None = None, model: str | None = None) -> LLMResult: ...
  def cost_usd(usage: Mapping[str, Any], cfg: Config) -> float: ...
  def estimate_tokens(text: str) -> int: ...     # ceil(len(text.encode("utf-8")) / 2.5) — 2.5 B/token, under the measured 2.67
  ```
  `client` defaults to `openai.OpenAI(api_key=cfg.LLM_API_KEY, base_url=cfg.LLM_BASE_URL, timeout=cfg.LLM_TIMEOUT_S, max_retries=0)` — `max_retries=0` because retrying is this class's job and the attempt count must be real. Tests always pass a fake `client` object exposing `chat.completions.create(**kwargs)`; no test constructs the SDK client. `spent_usd` is injected because `llm` may not import `audit` (P3-T10 passes `partial(llm_runs.month_spend_usd, conn)`). `model` defaults to `cfg.LLM_MODEL_PROPOSER`; P3-T09's `verify()` passes `cfg.LLM_MODEL_VERIFIER`.

  **2 · The call, exactly.**
  ```python
  self._client.chat.completions.create(
      model=model,
      messages=[{"role": "system", "content": system}, {"role": "user", "content": user}],
      response_format=response_format or {"type": "json_object"},
      extra_body={"thinking": {"type": self._cfg.LLM_THINKING}},
      timeout=timeout_s or self._cfg.LLM_TIMEOUT_S,      # the httpx gap guard — kept, not relied on
  )
  ```
  `"JSON"` must appear in `system` or DeepSeek rejects `json_object`; `complete()` raises `LLMPermanent` *before* calling if `"JSON" not in system` — a template defect is caught at the first test, not at the first live call. The mode is **always** sent, never defaulted: `extra_body` is present on every call, with whichever of `enabled|disabled` `Config` holds (DEC-042: the default is `disabled`; the knob stays for P7's paired ablation). **If anything in this module ever caches by prompt, `LLM_THINKING` is part of the key** — this adapter caches nothing; P7's harness does, and the rule is written here so the next reader sees it where the call is made.

  **3 · The deadline (DEC-033), and the test that proves it.** The SDK call runs in a `threading.Thread(daemon=True)`; the caller `join(timeout=deadline_s)`; if the thread is still alive → raise `LLMTimeout(f"model call exceeded {deadline_s} s wall-clock")` and abandon the thread (it is a daemon; its result is discarded on arrival — a discarded result is never returned to a later call: the thread writes into a per-call holder, not shared state). The httpx `timeout` stays as the network-gap guard. A timeout is `TransientError` and is **not** retried inside the adapter — the *job* retries with backoff (§6.5), which is what keeps a slow model from tripling its own latency. **Test:** a fake client whose `create` sleeps 3 s, `Config(LLM_TIMEOUT_S=1, …)` via `config.load(env_file=…)` or a constructed `Config` → `complete()` raises `LLMTimeout` and returns in under 1.5 s (`time.monotonic()` around the call). **Red step:** replace the thread + `join` with a direct call → the test takes 3 s and raises nothing → red.

  **4 · Retries, classification, and what is not retried.** Attempts = `1 + cfg.LLM_RETRY`. Retry on `openai.APIConnectionError`, `openai.APITimeoutError`, and any exception with `status_code >= 500`; pause `sleep(2.0 * attempt)` between attempts (injected `sleep` so tests do not wait). A `status_code` in `400..499` → `LLMPermanent` at once (no retry). `LLMTimeout` propagates at once (note 3). After the last attempt a transient error re-raises **as itself** (it is already `TransientError`-classifiable: `infra.errors.classify` maps `httpx.TransportError` and 5xx to transient — wrap any other transient in `TransientError` so the worker's classification is deterministic). Record `attempts` on the result? No — `LLMResult` is the fake's four fields; put `attempts` in `usage["attempts"]`, an extra key the fake does not set and no reader requires.

  **5 · Reading the response.** `content = message.content or ""` — `reasoning_content` is present as a `model_extra` key in thinking mode and is **never** read (`eval/smoke_test.py:836–853` is the working reference; a test feeds a message carrying both and asserts `content` only). `usage` flattened per `usage_dict` — `completion_tokens` **includes** `reasoning_tokens`, which are billed at the output price (`docs/smoke-test-D1-nothink.md` §3). `model = getattr(response, "model", None) or model`. `latency_ms = int((clock() - started) * 1000)` around the attempt that succeeded.

  **6 · Cost and the cap.** `cost_usd(usage, cfg) = usage["prompt_tokens"] / 1e6 * cfg.LLM_PRICE_IN_PER_M + usage["completion_tokens"] / 1e6 * cfg.LLM_PRICE_OUT_PER_M`, rounded to 5 decimals (`llm_runs.cost_usd` is `numeric(10,5)`; $0.00024 per call survives). Before *every* attempt: `if spent_usd() >= cfg.LLM_MONTHLY_USD_CAP: raise LLMBudgetExceeded(...)` — checked before the first attempt, and P3-T10 records `stopped_by='cap'` and `unavailable` (architecture §4.6). The two `prompt_cache_*` counters are carried in `usage` and not priced (`.env` has no price for them; the smoke report says P3 will want them — recorded, not billed).

  **7 · Token estimate.** `estimate_tokens()` is the pre-send budget check P3-T09 uses against `PROMPT_TOTAL_BUDGET_TOKENS`; it is character-based and deliberately conservative (2.5 bytes/token against the measured 2.67 — `docs/smoke-test-D1-nothink.md` §2: 33,564 bytes → 12,576 prompt tokens). The authoritative count is `usage`. Say both in the docstring.

  **8 · Never log a prompt.** No `print`/`logging` of `system`/`user` anywhere in this module — one structured line per attempt at most: `{"llm": "attempt", "n": attempt, "outcome": "ok|transient|permanent|timeout", "ms": …}`, and even that only through a `log: Callable[[dict], None] | None` the caller may inject (default: nothing).
