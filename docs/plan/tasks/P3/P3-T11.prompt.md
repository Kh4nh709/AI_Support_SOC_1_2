- **Design notes:**

  **1 · The loop, shared by the test and the CLI (`eval/triage_live.py` holds it; the test imports it).**
  ```python
  def run_live(conn, *, want_replay: int = 50, max_claims: int = 150, handlers=None, log=print) -> LiveSummary:
      handlers = handlers or {"triage": run_triage_job}          # the real handler, the real adapter (constructed inside from Config)
      claims = 0
      while _replay_proposer_rows(conn) < want_replay and claims < max_claims:
          before = _claimed_count(conn)
          run_forever(lambda: conn, handlers, once=True)          # exactly one claim; pull is NOT in the table, so nothing is pulled
          claims += 1
          if _claimed_count(conn) == before: break                # nothing left to claim
      return LiveSummary(claims=claims, replay_rows=…, wazuh_rows=…, ready=…, unavailable=…, failed_jobs=…, cost_usd_sum=…, verdicts=Counter(...), forced=…, missing_top=Counter(...))
  ```
  `_replay_proposer_rows` = `select count(*) from llm_runs r join alerts a on a.alert_id = r.subject_id where r.pipeline='triage' and r.role='proposer' and a.source='replay'`. Claims are consumed **through the real queue** — `claim_job` orders by `scheduled_at`, and the 76 `wazuh` heads were enqueued before the replay ones, so up to ~126 claims may be needed; `max_claims=150` bounds cost at ≤ 150 × 2 calls × ≈ $0.00024 ≈ **$0.07** (P1-T08: $0.0091 / 38 calls). Processed jobs leave the queue for good; the remaining ~230 are `make run-worker`'s (P4's pilot). The loop is idempotent: run twice, the second run makes 0 claims.

  **2 · The live test — names `.env`, skips without it, never touches `db`.**

          pytest.skip("live: DATABASE_URL / LLM_API_KEY / LLM_MODEL_PROPOSER not set — the Owner runs this from the primary checkout with .env")
      conn = psycopg.connect(cfg.DATABASE_URL)                   # NOT the db fixture — it would drop the database it is given
      summary = run_live(conn, want_replay=50, max_claims=150)
      # assertions: ≥ 50 replay proposer rows; every proposer row has gate_result IS NOT NULL and cost_usd > 0;
