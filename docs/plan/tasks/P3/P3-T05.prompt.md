  **2 · How `schemas.py` reads the compact notation** (this is the whole interpreter; write it as a table in the module docstring):
  | §6.2 value | means | validation |
  |---|---|---|
  | `"a\|b\|c"` where every alternative matches `^[a-z_]+$` and none is `string` | enum | value must be a `str` in the set; `"null"` among the alternatives admits `None` |
  | `"string"` | free string | `str` |
  | `"string\|null"` | nullable string | `str` or `None` |
