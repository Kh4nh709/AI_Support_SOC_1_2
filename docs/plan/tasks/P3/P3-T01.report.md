# Coder — P3-T01 report

## 1. Built

- **`backend/app/security/wrap.py`** — the only module that emits an `<untrusted_data …>` boundary.
  - `BLOCK_SOURCES` — closed `frozenset` of the six source names (five `triage_v2.reasons[].source`
    values plus `proposer`).
  - `TRUNCATION_MARKER = "[truncated]"`, `NONCE_REMOVED = "[nonce-removed]"`.
  - `new_nonce() -> str` — `secrets.token_hex(8)`.
  - `normalise(text) -> str` — `unicodedata.normalize("NFKC", text)`.
  - `strip_nonce(text, nonce) -> str` — `text.replace(nonce, NONCE_REMOVED)`.
  - `truncate_block(text, limit_bytes) -> tuple[str, bool]` — cuts on a UTF-8 byte budget,
    `errors="ignore"` so a trailing partial multibyte sequence is dropped rather than corrupted,
    marker appended inside the returned text.
  - `untrusted_block(text, source, *, nonce, limit_bytes=None, **attrs) -> Block` — runs
    normalise → strip_nonce → truncate (if bounded) → `html.escape(quote=False)` → render; raises
    `ValueError` on a source outside `BLOCK_SOURCES`; `nonce` is keyword-only with no default, so
    an omitted call is a `TypeError` at the call site (design note 5).
  - `Block` — frozen dataclass exactly as specified (`source`, `attrs`, `plain`, `escaped`,
    `truncated`, `dropped_bytes`, `rendered`); no third text representation added.
  - `_dropped_bytes(text, limit_bytes) -> int` — **one private helper**, not on the public
    surface list. `truncate_block`'s signature is fixed at `tuple[str, bool]` by the card, so it
    cannot also return the drop count; `untrusted_block` needs that count on `Block.dropped_bytes`.
    Rather than re-deriving it by parsing `truncate_block`'s marker text back out (fragile: couples
    the caller to the marker's exact format), both public functions call this one shared,
    side-effect-free byte-budget calculation.
- **`backend/tests/test_wrap.py`** (new) — 17 tests: the 14 named in the card plus three edge
  cases discovered while implementing (`test_no_truncation_when_limit_bytes_is_none`, the frozen
  dataclass invariant `test_block_is_frozen`, and `test_exact_rendered_example_from_the_card`,
  which pins acceptance 8's exact three-line output as a regression test).
