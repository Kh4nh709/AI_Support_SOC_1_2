The YAML uses the **DB** set — it is the frozen one and the loader writes straight into the column. Put a comment in the example and a short table in the format document giving the reading the plan proposes: `crown_jewel`, `high` → `high`; `normal` → `medium`; `low` → `low`; host absent from the inventory → `unknown`; and G8′'s "asset.criticality = high" therefore blocks auto-close for `crown_jewel` **and** `high`.   **`backend/app/enrichment/inventory.py`** — `validate()` and helpers, nothing else. Public surface:
  ```python
  def validate(paths: Sequence[str | Path] | None = None) -> list[str]:
      """Return human-readable problems, one per line; an empty list means the files are usable.

      paths defaults to INVENTORY_PATHS from the environment, else the three conf/ defaults.
      """
  def validate_assets(doc: object, source: str) -> list[str]: ...
  def validate_identities(doc: object, source: str) -> list[str]: ...
  def validate_iocs(rows: Iterable[Mapping[str, str]], source: str) -> list[str]: ...
  ```
  Rules — every message names the file, the index or key, and what was expected:
  - the file exists and parses (`yaml.safe_load`, `csv.DictReader`); a parse error is one message, not a traceback;
  - top level is a mapping with `version: 1` and the expected list key (`assets` / `identities`);
  - `hostname` / `username` / `value` present, non-empty, `str`, and **unique** within the file (duplicate primary keys are the failure the Owner will actually make);
  - `criticality` ∈ the DB set; `reputation` ∈ the DB set; `is_privileged` is a real bool, not the string `"false"` (a classic YAML trap — test it);
  - `expires_at` parses as ISO-8601 and carries a timezone; a row that has already expired is a **warning-shaped message** but still an entry in the returned list, prefixed `warning:` — the Owner needs to see it, and `validate()` returning non-empty is what `make`-style checks key on. Say in the docstring that callers may filter on the `warning:` prefix.
  - `owner` / `role`: optional, `str`, ≤ 200 characters.
  - unknown keys are reported (they are almost always a typo of a real one).
  **Constraints:** `enrichment/` may import `infra/` only (§4) — and `validate()` must run before any database exists, so it imports **no** database module at all: standard library plus `yaml`. No `print`; return the list. No I/O beyond reading the given paths.
