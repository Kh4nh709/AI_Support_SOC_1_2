## 3. Deviations

None. One bug was found and fixed during acceptance verification, inside this task's own scope (not a deviation from the card): `_maintenance_dsn` originally built the `postgres`-database DSN with `urllib.parse.urlunsplit`, which collapses `postgresql:///soc_test` (empty netloc, the exact DEC-008 no-docker form) into the invalid `postgresql:/postgres` — `urlunsplit` only keeps the `//` separator when netloc is non-empty or the scheme is in its hardcoded `uses_netloc` registry, and `postgresql` is in neither. Caught by running acceptance 3 for real (not by a pre-written unit test), root-caused, given two regression tests (`test_maintenance_dsn_preserves_the_socket_form_triple_slash`, `test_maintenance_dsn_preserves_host_and_credentials` in `test_conftest_helpers.py`), and fixed by building the DSN with an f-string instead of `urlunsplit`.

**Environment note, not a card deviation:** this host's git checkout runs multiple task branches through one shared working directory plus per-task worktrees (`../AI_Support_SOC_1_2-P0-T04` already existed for P0-T04). Partway through this task another agent's `git checkout` for `task/P0-T05` moved the shared checkout's `HEAD` out from under this task's in-progress branch. No commits were lost or mixed — all new files for this task were still untracked on disk (untouched by `checkout`), and the other agent's staged P0-T05 files were left untouched throughout. Recovered by creating `../AI_Support_SOC_1_2-P0-T03` as a dedicated worktree (`git worktree add`), moving this task's files into it, reapplying the `scripts/migrate.sh`/`.env.example` edits there, and restoring the shared directory's copies of those two files to `HEAD` so no trace of this task was left behind for the other task. All work in this report and all six commits were made from that worktree. **Recommendation for the Director:** have each coming task branch from a dedicated worktree from the start (as P0-T04 already does) rather than the shared primary checkout, to avoid a repeat.
