## 1 · Built

- `backend/app/web/handlers/__init__.py` — `iter_handlers() -> dict[str, Handler]` (discovers every
  module under this package, sorted by name, and keys the result by each module's `JOB_TYPE`;
  `AttributeError` if a module lacks `JOB_TYPE` or `handle`, `PermanentError` naming the module if
  `JOB_TYPE` is outside `app.infra.jobs.JOB_TYPES` or already claimed by another module) and
  `iter_timeouts() -> dict[str, str]` (same walk, collects `STATEMENT_TIMEOUT` only from modules that
  declare it).
- `backend/app/web/handlers/pull.py` — re-export: `JOB_TYPE = "pull"`, `handle = app.infra.puller.pull_job`.
- `backend/app/web/handlers/pipeline.py` — re-export: `JOB_TYPE = "pipeline"`,
  `handle = app.soar.pipeline.run_pipeline_job`.
- `backend/app/web/handlers/triage.py` — re-export: `JOB_TYPE = "triage"`,
  `handle = app.tier1.triage.run_triage_job` (the bare function, not a partial/lambda — its
  keyword-only `adapter` stays exactly what `test_g7_llm_off.py` and `test_triage_job.py` monkeypatch).
- `backend/app/web/worker.py` (rewritten, 10 lines added / 9 removed against `main`) — `HANDLERS =
  iter_handlers()` and `TIMEOUTS = iter_timeouts()` replace the old dict literal; `main()` now calls
  `run_forever(lambda: conn, HANDLERS, once="--once" in argv, timeouts=TIMEOUTS)`. Everything else in
  `main()` (`config.load()`, `db.connect()`, the single-flight `enqueue(conn, "pull", "indexer")`, the
  commit) is unchanged, line for line.
- `backend/tests/test_worker_handlers.py` — 8 pure tests (no `db` marker): the seven named in the
  card's design note 4, plus one more the card's own design note 5(c) calls for (see §3).
