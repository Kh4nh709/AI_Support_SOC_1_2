  `alert_id`, until `tokens(user) + tokens(system)` is within **± 2 %** of `CASE_PROMPT_BUDGET_TOKENS`. Token
  count is `len(text) / 4` rounded — the same crude estimator `eval/smoke_test.py` uses — **and the report says
  so in one sentence**, together with the exact byte count, so a reader can redo the arithmetic with a real
  tokeniser. A `--budget-tokens` flag defaults to the `Config` value and exists so the report can carry one
  control point at the ① class.

  **3 · The comparison that makes the number mean something — and the one the brief does not ask for.** Run the

  **4 · The ceiling, which is the finding the Director actually needs.** The report must carry, as its own

  index and say you did not re-run it — **do not** query `soc_dev`). State plainly what follows: the 60 k arm
  measures a class this deployment never reaches, and the 12.8 k arm measures the class it actually will.
  Both numbers go in the summary table. **Reporting only the 60 k arm would be a different way of measuring
  the wrong thing, which is the mistake DEC-032 exists to name.**

  **5 · Sending, caching and the spend guard.** Use `app.llm.adapter` — not a hand-rolled client — so the
  measurement inherits DEC-033's wall-clock deadline, the retry policy and the monthly-cap check that
  production will have. `--calls N` (default **30**) repeats the call and reports p50/p95 over the samples;
  `--max-spend-usd` defaults to **0.50** and aborts before the call that would cross it, printing the spend so
  far (P1-T08's guard). A response cache keyed on `sha256(model + system + user + LLM_THINKING + budget)` —
  **`LLM_THINKING` in the key is not optional**: DEC-042 records that leaving it out silently replayed one

  **6 · What is recorded per call.** `latency_ms` (wall clock around the adapter call), `input_tokens`,
  `output_tokens`, `cost_usd` (from the usage object and `LLM_PRICE_*`, never estimated), whether the response

  **8 · Tests (`backend/tests/test_investigate_measure.py`, pure — `-m "not db"`, no live call).**

  budget changes, and **does not** change when only `--calls` changes; `--max-spend-usd` aborts before the
