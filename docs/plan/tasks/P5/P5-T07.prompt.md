  duplicates, show *"đợt tấn công đang tiếp diễn — bộ đếm đang tăng"* with `last_seen_at` (P7-2).

  **5 · Tests (`backend/tests/test_pages_cases.py`, `db`).** `TestClient` with `get_conn` overridden and a real

  session gets a redirect to `/login` or a 403 per `base.html`'s convention, not a stack trace.
